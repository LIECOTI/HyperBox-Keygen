# HyperBox-Keygen
Keygen For HyperBox (Xiaomi VelaOS)

## Installation & Usage

1. Download the `Keygen.py` file from the repository.
2. Run it in your terminal:
   ```bash
   python Keygen.py
   ```

> **Note for Windows users:** Be sure to run the script via the terminal (CMD or PowerShell) rather than double-clicking it, so the window doesn't close immediately after execution.

---

### Tested Environment
Tested on the following setup:
* **Device:** Xiaomi Smart Band 10
* **System:** HyperOS 3.2.7
* **Software:** HyperBox 3.0.2
